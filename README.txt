FLOWBOARD — PROJECT MANAGEMENT DASHBOARD
=========================================

Files:
- index.html  : HTML structure and forms
- style.css   : responsive dashboard styling
- script.js   : interactive functionality and localStorage data
- README.txt  : these instructions

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or Firefox.
3. Navigate between Overview, Projects, My Tasks, and Team.
4. Try creating projects, adding tasks, changing task statuses, and adding team members.

FEATURES
- Dashboard statistics and project progress
- Create/search/filter projects
- Add tasks and update task status
- Priority labels and due dates
- Add/remove team members
- Delete projects and associated tasks
- Responsive mobile and desktop layout
- Saves demo records in browser localStorage

IMPORTANT FOR INTERNSHIP SUBMISSION
- Replace demo names and sample data with your own project details where appropriate.
- Test the features and take screenshots.
- Follow your internship portal's instructions about ZIP/GitHub/live URL.
- This is a frontend-only educational demo. Data is stored in the current browser and is not shared between devices. No authentication or backend database is included.
